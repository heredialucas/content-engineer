# Portfolio — Lucas

## Descripción

Portfolio personal de Lucas: diseñador y desarrollador web full-stack freelance. Muestra proyectos propios y de clientes, con foco en interfaces animadas, rendimiento y productos web completos de punta a punta (del diseño al deploy).

## Servicios

- Diseño y desarrollo de sitios y landings animadas de alta conversión
- Desarrollo de aplicaciones web completas (front + back)
- E-commerce: storefronts, catálogos, carritos y paneles de administración
- Productos SaaS y dashboards internos

## Tecnologías

- Next.js 16 + React 19 (App Router)
- TypeScript end to end
- Tailwind CSS 4
- Framer Motion y GSAP para animaciones de alto nivel
- Lenis para scroll suave
- Node.js para backends y APIs REST
- Internacionalización (i18n) español / inglés

## Proyectos destacados

- Portfolio personal (este sitio): landing animada con i18n, stack Next.js 16 + React 19
- E-commerce completo con panel de administración (front React + backend Node)
- Medpharm: producto web para el sector farmacéutico
- Nutri App: aplicación de gestión nutricional
- Medicus Apotheke: plataforma para farmacia

## Propuesta de valor

Un solo responsable para todo el producto: diseño, animación, desarrollo y deploy. Interfaces que se sienten premium (animaciones físicas, micro-interacciones, scroll cinematográfico) sin sacrificar performance ni SEO. Entregas rápidas y comunicación directa, sin capas de intermediarios.

## Público objetivo

- Emprendedores y PYMEs que necesitan su primer producto web serio
- Agencias que delegan desarrollo front de alto nivel visual
- Startups tempranas que necesitan MVP rápido y con buena presencia

## Tono de comunicación

Directo y concreto, profesional pero cercano. Sin tecnicismos innecesarios con clientes; precisa y técnica cuando el contexto lo amerita. Español rioplatense.
