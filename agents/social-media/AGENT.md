# Agente: Social Media

## Responsabilidad
- Prepara la publicación completa: caption, hashtags, formato, duración y ubicación de archivos.
- Empaqueta todo en un post file (`posts/<id>.md`) listo para revisión manual.
- En el futuro: será responsable de enviar contenido a Buffer (PublishProvider).

## Reglas
- No publica nada automáticamente: el pipeline es revisión manual primero.
- El post file debe incluir todo lo necesario para publicar sin abrir el video.
